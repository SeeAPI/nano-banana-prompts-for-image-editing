## 🧭 使用方法与模型选择

选择模型 → 上传 Before 中的原图与参考图 → 复制提示词并替换占位符 → 生成结果。

多图输入按图片编号上传；需要继续调整时，在同一会话中描述修改。

| 模型 | 优势与适用场景 | 主要取舍 |
| --- | --- | --- |
| Nano Banana | 适合沿用初代模型的已有案例 | 旧款模型；官方建议迁移至更新版本 |
| Nano Banana 2 | 兼顾速度与质量，擅长多参考图处理与一致性 | 本仓库日常编辑的默认推荐；复杂精修可考虑 Pro |
| Nano Banana 2 Lite | 速度最快、成本最低，适合简单编辑与批量尝试 | 仅支持 1K；未针对多参考图和连续多轮编辑优化 |
| Nano Banana Pro | 适合复杂视觉任务、品牌一致性与精细控制 | 面向高要求任务；简单任务可先尝试 2 或 Lite |

**选型建议：先选 Nano Banana 2；简单批量任务选 Lite，复杂精修选 Pro。**

模型能力依据 [Google 官方说明](https://ai.google.dev/gemini-api/docs/image-generation)，选型建议由 SeeAPI 整理；不代表每条提示词均已在四款模型上测试。
