## 🧭 How to Use & Choose Your Model

Choose a model → Upload the original and reference images shown under Before → Copy the prompt and replace its placeholders → Generate your edit.

Upload multiple images in their numbered order. To refine the result, describe your next change in the same conversation.

| Model | Strengths & best uses | Trade-offs |
| --- | --- | --- |
| Nano Banana | Revisit existing cases built with the original model | Legacy model; Google recommends moving to newer versions |
| Nano Banana 2 | Balances speed and quality; strong multi-reference handling and consistency | Our default for everyday editing; consider Pro for complex refinement |
| Nano Banana 2 Lite | Fastest and lowest cost; useful for simple edits and batch exploration | 1K only; not optimized for multiple references or sequential multi-turn editing |
| Nano Banana Pro | Complex visual tasks, brand consistency, and precise creative control | For demanding tasks; try 2 or Lite first for simpler work |

**Quick pick: start with Nano Banana 2; choose Lite for simple batch tasks and Pro for complex refinement.**

Capabilities follow [Google’s official documentation](https://ai.google.dev/gemini-api/docs/image-generation). Selection advice is curated by SeeAPI; it does not imply every prompt has been tested on all four models.
